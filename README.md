# Azam Rizwanshah | Portfolio

Professional portfolio website showcasing expertise in DevOps engineering, AI agent workflows, and full-stack development.

## 🚀 Live Site
Check it out at: [https://azamshah.me](https://azamshah.me)

## 🛠 Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Integration**: GitHub API (Axios)
- **Deployment**: GitHub Actions

## 🏗 Features
- **Dynamic Projects**: Automatically fetches and displays real-time repositories from GitHub.
- **Modern UI**: Dark mode, glassmorphism, and neon gradients.
- **Responsive**: Fully optimized for all screen sizes.
- **CI/CD**: Automatic deployment to GitHub Pages via Git Actions.

## 📦 Local Setup
1. Clone the repo: `git clone https://github.com/AzamShah668/azamshah.me.git`
2. Install dependencies: `npm install`
3. Start dev server: `npm run dev`
4. Build for production: `npm run build`
